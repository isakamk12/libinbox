# 図書館ホームページ 3Dインタラクティブ・ベーステンプレート (libinbox)

本プロジェクトは、誰でも簡単に美しいデザインの図書館用ホームページや作品ポートフォリオ（カタログ）を立ち上げられる汎用ベーステンプレートです。

最も本らしくて美しい「3D本棚ホバー」および「3D見開きページフリップ（めくり）」という**2大王道演出のみに完全統一し、すべての書籍・作品でこれらを共通して使い回す最高品質の極小・頑健設計**を採用しています。

---

## 🌟 主な特徴と「使い回しによる頑健化」

1. **他者も使える簡単・安全カスタマイズ**
   HTMLやCSSなどのプログラムコードを編集することなく、設定ファイル（JavaScript）のテキスト部分を書き換えるだけで、図書館名や本棚の本、お知らせデータをすべて自動で変更・反映できます。
2. **磨き上げられた2大王道演出への完全統一**
   不自然でめちゃくちゃな演出（カード裏返し、巻物、本棚回転など）を一切排除し、最も美しく調整された王道表現のみに絞り込みました。
   - **本棚ホバー (`shelf.css`)**: 本棚から本を手前にスッと引き出して傾く「クラシック・プル演出」
   - **本を開く演出 (`book.css`)**: 画面中央で表紙が左へパタッとめくれて開く「3D見開きフリップ演出」
3. **破損リスクがゼロの「極小ロジック」**
   演出の切り替えやバリエーション管理に伴う複雑な動的JS条件分岐を完全に削除しました。JSは本棚データと作品カタログデータをそれぞれ流し込むだけの**極限までシンプルで壊れようのないコード**になっています。
4. **文字反転バグ完全対策済**
   表表紙をめくった際、裏側から文字が鏡像（反転）で透けてしまう問題に対し、3D Transformsの `backface-visibility: hidden` 処理を組み込んで完全に解決しています。
5. **完全レスポンシブ対応**
   PCの大画面では2ページ見開きの美しい本が表示され、スマートフォンの画面では自動的に1カラムの読みやすいレイアウトに最適化されます。

## 📂 ディレクトリ構成

```text
libinbox/
├── index.html            # メイン画面（1つの本棚、1つの作品ギャラリーのシンプルな統合）
├── README.md             # この説明書
├── css/
│   ├── variables.css     # デザインシステム（配色・文字フォント・共通変数）
│   ├── main.css          # 全体レイアウト、お知らせ、ご利用案内、ギャラリーカード
│   ├── shelf.css         # 3D本棚と「本を引き出す共通ホバー演出」のスタイル
│   └── book.css          # 「本を開く共通3Dめくり演出」のスタイル
└── js/
    ├── config.js         # 【カスタマイズ用】図書館情報やお知らせのデータ
    ├── books-data.js     # 【カスタマイズ用】本棚背表紙データ＆作品紹介カタログデータ
    └── main.js           # 描画とモーダル開閉を制御する極小ロジック（破損リスクなし）
```

## 🛠️ カスタマイズ方法

### 1. 図書館名や連絡先、お知らせの変更
[js/config.js](file:///C:/Users/rpgmi/Documents/GitHub/libinbox/js/config.js) をテキストエディタで開きます。
以下の項目を自分の情報に書き換えて保存してください。

```javascript
const LibraryConfig = {
  title: "あなたの図書館・ポートフォリオ名",
  subtitle: "サブタイトル",
  // ...開館時間やお知らせ配列も同様にテキストを書き換えるだけで自動反映されます
};
```

### 2. 本棚に並べる本、およびカタログ作品の追加・編集
[js/books-data.js](file:///C:/Users/rpgmi/Documents/GitHub/libinbox/js/books-data.js) をテキストエディタで開きます。
背表紙データ (`LibraryShelfBooks`) および作品ギャラリーデータ (`LibraryShowcaseBooks`) は、余分な演出指示パラメータを持たないため、シンプルに要素を増減するだけで安全に編集できます。

```javascript
const LibraryShowcaseBooks = [
  {
    id: "showcase-vtuber",
    title: "VTuberアーカイブ",       // 表紙に表示されるタイトル
    author: "rpgmi",               // 著者/製作者名
    color: "var(--spine-red)",     // 表表紙のテーマカラー
    textColor: "#ffffff",          // 表紙の文字色
    decorType: "gold-border",      // 背表紙・表紙の装飾デザイン

    chapter: "Vol. 1",             // 開いた本の右ページヘッダー
    description: "あらすじカードに表示される短い概要",
    content: "ここに紹介文や詳細テキストを記入します。クリックすると自動的に共通の美しい3Dフリップで開きます。" 
  },
  // ...
];
```

## 🚀 動作方法

1. 特別なサーバービルドやコンパイルは不要です。本フォルダをWebサーバーにアップロードするだけで即座に公開できます。
2. ローカル環境で確認する際は、`index.html` をダブルクリックしてブラウザで開くか、VS Codeの「Live Server」などの簡易ローカルサーバーをご使用ください。
